# NetPrompt Milestone II

## Repository Structure

```text
milestone-II/
│
├── compile_all_sfc_p4.sh
├── p4_programs/
```

## Root Files

### compile_all_sfc_p4.sh

Compiles all SFC-specific P4 programs:

```text
low_latency.p4
reliable_relay.p4
energy_aware.p4
bandwidth_optimized.p4
        ↓
p4c-bm2-ss
        ↓
compiled_p4/*.json
```

## p4_programs/

Contains source P4 programs implementing data-plane behavior.

### low_latency.p4
- Latency optimized forwarding
- Traffic prioritization
- Queue assignment
- Used by LowLatencyVideoSFC

### reliable_relay.p4
- Backup path support
- Failure-aware forwarding
- Relay-aware routing
- Used by ReliableRelaySFC

### energy_aware.p4
- Energy conservation
- Traffic filtering
- Selective forwarding
- Used by EnergyAwareSFC

### bandwidth_optimized.p4
- Throughput optimization
- Traffic shaping
- Flow aggregation
- Used by BandwidthOptimizedSFC

## compiled_p4/

Compiled BMv2 JSON pipelines generated by p4c-bm2-ss.

## p4_rules/

Runtime forwarding policies for single-switch deployments.

## p4_multihop_rules/

Switch-specific runtime rules for:

```text
s1 = Access Switch
s2 = Primary Relay
s3 = Backup Relay
```

Supports:
- Multi-hop routing
- Relay selection
- Backup path activation
- Failure-aware forwarding

## experiments/

Core orchestration layer.

### update_topology_state.py
Updates Neo4j topology state.

### kg_path_selector.py
Selects PrimaryPath or BackupPath from KG state.

### path_aware_sfc_selector.py
Selects SFC based on scenario and topology conditions.

### sfc_to_p4_mapper.py
Maps SFC → P4 program → runtime rules.

### sfc_to_multihop_mapper.py
Maps SFC → s1/s2/s3 rule sets.

### dynamic_sfc_p4_multihop_experiment.py
Runs final multi-hop architecture.

### run_netprompt_milestone2_final.sh

Complete pipeline:

```text
Scenario
      ↓
Topology Update
      ↓
KG Path Reasoning
      ↓
SFC Selection
      ↓
P4 Mapping
      ↓
Rule Installation
      ↓
Multi-Hop Execution
      ↓
Result Parsing
      ↓
Neo4j Update
```

## kg/

Knowledge Graph layer.

Stores:
- Drone topology
- Infrastructure nodes
- SFC templates
- P4 policy mappings
- Path decisions
- Runtime results

Key entities:

```text

edge-node
Drone_1 ... Drone_10

EnergyAwareSFC
BandwidthOptimizedSFC

```

## Final Architecture

```text
Mission Scenario
       ↓
Neo4j Topology Update
       ↓
KG Path Reasoning
       ↓
Path-Aware SFC Selection
       ↓
SFC → P4 Mapping
       ↓
Multi-Hop Policy Mapping
       ↓
BMv2 Deployment
       ↓
Experiment Execution
       ↓
Result Collection
       ↓
Neo4j Feedback Update
```

This repository represents the final non-LLM NetPrompt Milestone II architecture and serves as the foundation for Milestone III, where LLMs will dynamically generate SFCs, path decisions, and P4 policies from mission intent.
